# Белово 03592 — интерактивна карта на масивите

Самостоятелен картографски проект само за **землище гр. Белово (ЕКАТТЕ 03592)**. Не използва код, репозитори, хостинг или база данни от AgroRadarBG.

## Съдържание

- Геореферирани работни карти 1 и 2, **стопанска 2026/2027 г.**, разделени в **12 WebP плочки** за надеждно зареждане в GitHub.
- **6309 архивни CAD контура от 26.07.2016 г.**, видими като отделен справочен слой, с търсене по стар CAD номер.
- Свободно приближаване и преместване, избор на лист, прозрачност, подробности за геометрична площ на исторически CAD контур, експортиране на PNG, споделяне на изглед и мобилен интерфейс.

**Ограничения:** Цветовете на масивите са пресъздадени от предоставените PDF карти; без надежден регистър не се приписват на конкретни ползватели. CAD слоят е от **2016 г.**, не е актуална кадастрална карта и не удостоверява собственост или право на ползване. Приложението не заменя официална скица.

## Разполагане

Това е статичен сайт, без npm или build стъпки. За локален преглед:

```bash
python -m http.server 8000
```

Отвори `http://localhost:8000`.

За GitHub Pages: в **Settings → Pages** за това репозитори избери **Deploy from a branch**, branch `main`, folder `/(root)` и запази. Стандартният адрес, след успешното активиране, е `https://petiazah.github.io/belovo-land-map/`. GitHub Pages за *private* репозитори зависи от плана и настройките; това не е доказателство, че сайтът вече е активен.

Алтернатива е отделен Cloudflare Pages проект от това ново репозитори, с preset **None** и output directory **`.`** — няма нужда от връзка с AgroRadarBG.

## Файлове

- `index.html` — интерфейсът;
- `assets/styles.css`, `assets/app.js` — стилове и логика;
- `assets/tiles/{west,east}-r{0,1}c{0,1,2}.webp` — високодетайлни картни плочки;
- `data/cad-2016.js` — геометрията на 6309 исторически CAD контура.

## Източници и георефериране

- `КАРТА 1 Белово.pdf` и `КАРТА 2 Белово.pdf` — работни карти на масивите за 2026/2027 г.;
- `03592-Нов_1.cad` — справочна CAD основа към 26.07.2016 г.

Позиционирането е в EPSG:32635 (UTM зона 35N) по координатните рамки на предоставените работни карти. Възможни са изменения и пространствени разминавания между двата времеви слоя.
